\# OWASP Juice Shop - DevSecOps Security Project



\## Project Overview



This project focuses on building and securing a DevSecOps pipeline using the

OWASP Juice Shop application.



The project demonstrates application containerisation, threat modelling,

secure coding, vulnerability identification and remediation, automated security

testing, secrets scanning, dependency scanning, and container image scanning.
